# 🎈 Blank app template

A simple Streamlit app template for you to modify!

## Relatório Série A (Sub-20 / Sub-23)

O PDF comparativo de minutos por temporada está em [`reports/serie_a_sub20_sub23_relatorio.pdf`](reports/serie_a_sub20_sub23_relatorio.pdf).

Para regenerar o relatório (dados FotMob + gráficos):

```bash
pip install -r requirements.txt
python scripts/generate_serie_a_relatorio.py
```

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/)

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
